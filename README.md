# Password

Animated OTP input for React. Supports 4–6 digits and masking.

Requires Node.js 20.9+.

```sh
npm ci
npm run dev
```

[Local demo](http://localhost:3000) · [Component](components/snippets/family-style-otp.tsx)

Demo codes: `1234`, `12345`, `123456`. No backend authentication.

Based on [Smintfy/ui-snippet](https://github.com/Smintfy/ui-snippet). [UI sources](components/richbox/README.md) · [MIT](LICENSE).
